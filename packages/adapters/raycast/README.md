# @raggle-ai/raycast-adapter

Raycast components and conversion utilities for Raggle local projects.

## Project picker

`ProjectPicker` reads the latest project snapshot generated by the locally installed
Raggle Raycast extension. Open Raggle once before using a consuming command so the
snapshot exists and is current. The list displays its project count in the section
title and supports indexed search across project names, repositories, keywords,
session titles, and GitHub owners.

```tsx
import { ProjectPicker } from "@raggle-ai/raycast-adapter";

export default function Command() {
  return <ProjectPicker onSelect={(project) => console.log(project.worktree)} />;
}
```

Pass `snapshotPath` when a command needs an explicit source instead of the default
sibling `raggle` extension support directory.
